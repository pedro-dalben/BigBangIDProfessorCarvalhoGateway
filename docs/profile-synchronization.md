# Sincronização de perfil

O perfil é coletado de forma assíncrona após a vinculação, cinco segundos após a entrada, por `/professor sincronizar` e no intervalo configurado. Moedas são strings decimais; falhas de um módulo deixam somente aquele módulo indisponível.

O snapshot inclui nome/UUID interno, rank quando fornecido, economia, profissões e os campos seguros da equipe Cobblemon. IP, coordenadas, inventário, mensagens, IVs, EVs, golpes e itens segurados nunca são enviados.
